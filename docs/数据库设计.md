# 数据库设计

- 数据库：`ai_blog`（MySQL 8.0+，utf8mb4 / utf8mb4_general_ci）
- 初始化脚本：`server/sql/init.sql`，种子数据：`server/sql/seed.sql`
- 外键策略：用户/博客删除采用级联（`ON DELETE CASCADE`）；分类删除置空（`SET NULL`）

共 14 张表：

| # | 表名 | 说明 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `users` | 用户表 | username/email（唯一）、password（bcrypt）、role（user/admin）、status（1 正常/0 禁用）、ai_style |
| 2 | `categories` | 博客分类 | name、slug（唯一）、sort_order、blog_count（冗余统计） |
| 3 | `tags` | 标签 | name（唯一）、color、ref_count |
| 4 | `blogs` | 博客文章 | user_id、category_id、title、content（Markdown）、summary、cover、keywords、status（draft/published/offline）、audit_status（pending/pass/reject）、is_ai_assisted、is_top、view/like/comment/favorite_count、word_count、published_at |
| 5 | `blog_tags` | 博客-标签关联 | blog_id、tag_id（联合主键） |
| 6 | `comments` | 评论（支持二级回复） | blog_id、user_id、parent_id、root_id、content、sentiment（情感标签）、sentiment_score、status（normal/hidden/pending）、is_ai_reply、like_count、report_count、ip_region |
| 7 | `likes` | 点赞（博客/评论通用） | user_id、target_type（blog/comment）、target_id（唯一约束防重复） |
| 8 | `favorites` | 收藏 | user_id、blog_id（唯一约束） |
| 9 | `view_logs` | 浏览记录（个性化推荐数据源） | user_id（游客可空）、blog_id、ip、stay_sec |
| 10 | `reports` | 举报 | user_id、target_type、target_id、reason、status（pending/resolved/ignored） |
| 11 | `ai_configs` | AI Agent 参数配置（后台可调） | config_key（唯一）、config_value、value_type（string/number/boolean/json）、description |
| 12 | `ai_logs` | AI 调用日志 | user_id、action、provider、model、prompt/completion_tokens、duration_ms、status、error_msg |
| 13 | `sensitive_words` | 敏感词库（内容审核规则） | word（唯一）、category（politics/porn/ad/abuse/other）、level（1 提示/2 替换/3 拦截）、enabled |
| 14 | `stats_daily` | 每日统计快照（定时任务写入） | stat_date（唯一）、pv、uv、new_users、new_blogs、new_comments、ai_calls |

## 核心关系

```
users 1───* blogs 1───* blog_tags *───1 tags
  │           │
  │           └───* comments (parent_id/root_id 自关联，支持楼中楼)
  │
  └───* likes (target_type/target_id)
  └───* favorites
  └───* view_logs
  └───* reports (举报人)
  └───* ai_logs
```

## 索引要点

- `blogs`：`idx_status_pub(status, published_at)`（前台列表）、`idx_hot(status, view_count)`（热门）、`ft_title_summary`（ngram 全文检索，支持中文）
- `comments`：`idx_blog_status(blog_id, status, created_at)`、`idx_sentiment`
- `likes/favorites`：唯一约束 `(user_id, target_type, target_id)` 保证幂等
- `ai_logs`：`idx_action`、`idx_user_time` 支撑用量统计

> 统计字段（`blog_count` / `*_count`）为冗余计数，由 service 层在写操作后维护，避免高频聚合查询。
